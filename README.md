# Чат-бот ВКонтакте для автоматизации внутренней информации и согласования документов

> Дипломный проект (09.02.07 Информационные системы и программирование)  
> Разработка расширения для конфигурации «1С:ERP Управление предприятием 2»

## 📌 Описание проекта

Проект представляет собой **интеграцию мессенджера ВКонтакте с учётной системой 1С:ERP**.  
Цель – автоматизировать процессы получения кадровой информации и согласования документов сотрудниками ООО «Электронная корпорация Радуга».

Чат-бот позволяет:
- Авторизоваться через ФИО + корпоративную почту с подтверждением по одноразовому коду.
- Искать контакты (email, телефон) сотрудников по ФИО.
- Выводить списки сотрудников по должности.
- Согласовывать документы «Заявка на расходование денежных средств» с отправкой PDF и inline-кнопками.

## 🚀 Основные возможности

| Функция | Описание |
|---------|----------|
| 🔐 Многоуровневая аутентификация | Проверка ФИО в 1С, отправка 6-значного кода на корпоративную почту |
| 👥 Поиск сотрудников | Поиск по части ФИО – вывод email и рабочего телефона |
| 📋 Вывод по должности | Список всех сотрудников должности с контактами |
| 📄 Согласование документов | Отправка PDF-формы заявки руководителю, inline-кнопки «Согласовать/Отклонить» |
| ⏰ Напоминания | Автоматическое уведомление о неотвеченных заявках при любом сообщении боту |

## 🧱 Технологический стек

- **1С:Предприятие 8.3** (расширение конфигурации без снятия с поддержки)
- **HTTP-сервисы 1С** (приём webhook-вызовов от VK)
- **VK Bot API** (callback API, отправка сообщений, inline-клавиатуры, загрузка документов)
- **Apache** (публикация HTTP-сервисов)
- **Tuna** (туннель для внешнего доступа при отсутствии статического IP)
- **Встроенный язык 1С** (JSON, HTTP-запросы, работа с регистрами и документами)
- **Vanessa Automation** (BDD-автотесты для критического функционала)
